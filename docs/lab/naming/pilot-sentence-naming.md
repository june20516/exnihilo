# 문장 던전: 세계관으로 이름을 입혀야 할 대상

지금 화면과 규칙에 쓰는 이름은 모두 **임시 이름(기능 설명)**이다. 시놉시스와 세계관이 정해지면 아래 목록을 한 번에 채운다. 이름을 정할 때 지킬 원칙은 다음과 같다.

- **문자 그대로 읽힌다.** 카드와 규칙의 효과는 이름을 문자 그대로 읽은 결과여야 한다. 예를 들어 "독을 뿜는 거미"는 거미가 독을 뿜는 주체라는 뜻이다. 이름을 바꿀 때 효과의 방향(누가 하고 누가 겪는가)이 달라지면 안 된다.
- **한 축은 한 계열의 말로 묶는다.** 예를 들어 지속 시간 이름들은 서로 비교되는 말이어야 한다.
- **노출 여부**: "노출"은 플레이어가 화면에서 보는 말이고, "내부"는 코드와 문서에만 쓰는 말이다. 내부 이름도 세계관 이름이 정해지면 문서 용어를 맞춘다.

임시 이름 중 이미 세계관 냄새가 나는 것(서고, 망각, 낭독, 원문)은 그대로 남길 후보로 표시했다.

## 1. 카드 속성 (새로 생기는 축)

| 축 | 임시 값 | 뜻 | 노출 | 메모 |
|---|---|---|---|---|
| **지속 시간** | 이번 낭독 / 적 차례까지 | 형용사가 만든 상태가 얼마나 남는가 | 노출(카드·개체 표시) | 볼륨 단계에서 값이 늘어날 수 있다(예: 2턴, 전투 끝까지). 짧은 것부터 긴 것까지 한 계열의 말로 이름 짓는다. |
| **등급** | (없음, 볼륨 단계) | 같은 효과의 변형 단계(반쪽, 한시적, 두 활용형 등) | 미정 | `docs/lab/backlog/pilot-sentence.md` 참조 |
| **희귀도** | 시작 / 보통 / 비범 / 희귀 | 상점 등장 가중치와 가격 | 지금은 내부(상점 가격에만 드러남) | 노출하려면 이름이 필요하다. |
| **품사 묶음** | 명사 / 타동사 / 자동사 / 형용사 / 부사 / 연결어 / 오염 | 카드 종류 | 노출(카드 태그) | 문법 용어 그대로 둘지, 세계관 이름(예: 필사 도구 이름)을 입힐지 결정 필요. "오염"(쓸 수 없는 카드)은 이미 세계관 이름이다. |

## 2. 문장과 슬롯

| 임시 이름 | 뜻 | 노출 | 메모 |
|---|---|---|---|
| 문장 / 내 문장 / 예고 문장 | 한 턴에 짓는 행동, 적이 다음에 할 행동 | 노출 | "예고 문장"은 적의 의도다. 세계관 이름 후보로 둔다. |
| 절 / 둘째 절 | 연결어로 이어지는 문장 단위 | 노출 | |
| 주어 / 목적어 / 동사 (칸) | 슬롯 역할 | 노출 | 문법 용어가 곧 규칙이라 바꾸면 이해가 흐려질 수 있다. 바꿀지부터 결정한다. |
| 수식어 칸 | 형용사·부사를 놓는 칸 | 노출 | |
| 빈칸 / 생략 / 비어 있음 | 놓지 않은 자리(생략된 주어·목적어, 빈 동사) | 노출 | "생략"은 유물 "생략의 미학"과 이어진다. |
| 원문 / 내 단어 | 적 단어 / 내 카드(슬롯 머리 표시) | 노출 | "원문"은 세계관 이름 후보다. |
| 낭독 | 문장을 실행하는 행동(버튼) | 노출 | 세계관 이름 후보다. |
| 계산식 | 피해를 계산하는 식 표시 | 노출 | 기능 표시라 그대로 둬도 된다. |

## 4. 상태(버프·디버프)

| 임시 이름 | 뜻 | 노출 | 메모 |
|---|---|---|---|
| 보호 | 피해를 먼저 막는 값 | 노출 | |
| 독 | 턴 끝 피해 | 노출 | |
| 약화 / 취약 / 힘 | 주는 피해 ×0.75 / 받는 피해 ×1.5 / 주는 피해 + | 노출 | 형용사 상태(눈멂, 금이 감)와 효과가 겹친다. 같은 계열로 묶을지, 상태와 형용사를 하나로 합칠지 결정이 필요하다. |
| 빙결 | 다음 행동 무효 | 노출 | |
| 형용사 상태(눈멂, 단단함, 금이 감 등) | 형용사로 생긴 상태 | 노출(새로 생김) | 형용사 활용형(눈먼 → 눈멂)을 그대로 쓰는 것이 문자 그대로 원칙에 맞다. |

| 상점 / 보상 / 팔림 / 넘어가기 | 층 사이 구매 | 노출 | 상점 주인이나 장소 이름 후보 |

## 6. 유물 (이미 이름이 있는 것)

긴 문장, 수식의 사슬, 강세, 생략의 미학, 허수아비 화자, 독의 문법, 울림, 메아리. 모두 문법·수사 용어로 지어 세계관과 잘 맞는다. 세계관이 정해지면 "유물"이라는 묶음 이름만 정하면 된다(예: 문법서, 규칙, 인장).
