## Plan 1 결정 요약

controller Ruling(`progress.md`)을 주제별로 묶었다. 번호는 Ruling 번호다.

### 콘텐츠와 검증
- 1: scope가 빠진 비 gaze 트리거는 `perceived`로 쓴다.
- 2, 7: `validateShow`의 performers에는 무대 출연자와 bench를 합쳐 넘긴다. 코너 startTag와 corner 트리거 태그는 검사하지 않는다(태그 출연자가 없는 코너 허용, 출연자 재사용).
- 26: 관객 카메라 id는 `audienceCam`. 엔진의 관객 source `audience`·`broadcast`는 예약 id로 막는다. 스위처 키 1·2·3 = `wide`·`close`·`audienceCam`.
- 28: 과열된 조명을 점프·날아간 출연자가 닿는 높이(중심 y 2.5)로 내렸다.

### 물리
- 9: `Contact.fasterId`는 직전 속력이 큰 참여자(출연자 또는 장비). 떨어지는 조명이 충돌의 원인이 된다.
- 10, 24: 바닥 충격 강도는 내려오는 수직 속도(max(0, -vy))로만 판정한다. 미끄러짐과 이륙은 사고가 아니다.
- 11: 물리 상수도 모두 `balance.ts`에 둔다.
- 12: 세트 벽 position.y는 바닥면, 조명은 중심.

### 현상, 반응, 연쇄
- 3: 출연자가 아닌 source(장비, 관객, 방송)의 존재감은 1.
- 13: 반응 후보는 강도 → 정의 순서 → 이벤트 id 순. chance는 고른 후보 하나에만 rng 1회, 실패하면 다음 후보로 넘어가지 않는다.
- 14: 반응 쿨다운 key는 현상 종류 하나(spec 2.6).
- 17: 관객 자동 반응(송출 중 소음, 웃음 전염)은 엔진이 balance 수치로 처리하고 쿨다운을 쓴다.
- 18, 29: 맞은 출연자는 그 충격을 다음 충돌의 원인으로 이어받되, 움직임 원인은 2초(`MOTION_CAUSE_SECONDS`) 뒤 만료된다.
- 23: 카메라 시선(gaze)으로 시작한 반응은 깊이 1에서 시작한다.

### 개입과 광고
- 16, 16a: 엇나감 확률은 이번 지시 전의 누적 피로로 계산한다(첫 지시는 엇나가지 않음). 확률 0이면 rng를 쓰지 않는다. 이탈한 출연자·없는 id에 지시하면 throw하므로 UI가 막는다.
- 4: 광고는 `{ type: 'ad', effects }` 입력 하나. 그 스텝에 효과를 적용하고 `adBreak`로 바뀌며, `resumeFromAd()`로 돌아올 때 시청자 일부가 이탈한다(spec 5.5). 모든 상태 변화가 입력 로그에 남는다.
- 36: 광고 입력을 받은 스텝도 스텝 수를 1 올린다(물리·현상 없음). step 번호와 입력 묶음이 일대일이라 replay가 재개 직후 입력을 광고 묶음과 섞지 않는다. 코너 경계가 광고 스텝이면 재개 뒤 첫 스텝에 코너가 시작된다.
- 5a(5 수정): 광고 패널을 평상시에 열면 정상 속도, 시간 제한 없음, 취소 가능. 개입 중에 열면 그 개입은 세지 않고 닫되, 남은 시간 동안만 `INTERVENTION_SPEED`를 이어받고 다 되면 패널이 취소된다.
- 20, 25: `step(inputs)`는 입력 묶음 전체를 검증한 뒤 적용한다(원자적).
- 21: 대기 출연자가 없으면 외적 세팅을 고를 수 없다(`benchLeft`).
- 22: 재정비는 광고 전 대기 이벤트를 비운다.

### 화면
- 15: 카메라 각도는 도 단위, +x가 0도, 반시계.
- 19: `autoSlowmo`는 마지막 계기를 들고 있고, UI는 `autoSlowmo.step`이 바뀔 때만 자동 슬로모션을 건다.
- 30: 이탈자 판단은 `ActorView.departed`. 개입 대상 목록은 출구로 걸어가는 출연자(`walkedOut`)도 뺀다(지시하면 엔진이 throw).
- 31: `actorAt`은 캔버스 논리 좌표(1280×720). 화면은 캔버스를 960×540으로 줄이고 클릭 좌표를 환산한다(`clientToCanvas`).
- 32, 33: 장비 종류는 `EquipmentView.kind`, 좌표 변환은 `geometry.ts`. 말풍선이 모두 막히면 겹쳐도 둔다.
- T11: 개입은 지시 하나로 닫힌다. 시간이 다 되거나 닫거나 광고 패널을 열면 개입으로 세지 않는다. 한 프레임의 실제 시간은 `MAX_FRAME_REAL_SECONDS`(0.25초)로 잘라 탭 복귀 때 개입·광고 타이머가 한꺼번에 끝나지 않게 했다. `?seed=정수`로 시드를 고정한다.

## 사용자 플레이 1회차 피드백과 즉시 수정 (2026-11-26)

### 피드백
- 가만히 두면 아무 일도 일어나지 않는다(가장 어색했던 점). 무조건 개입해야 하고 사건이 일어나기 매우 어렵다. 로그는 "방송에 정적이 이어진다"뿐이다. 수치 효과 없는 문구라도 읽는 재미가 있었으면 한다(예: "누구누구가 코를 판다", "깜빡 존다"). 캐릭터마다 버릇을 정의하거나, 캐릭터끼리 상호작용하거나, 로그 앞뒤가 이어지면 좋겠다.
- 캐릭터가 왜 그렇게 행동하는지, 특성과 스펙을 볼 수 없어 이해가 안 된다.
- MC는 카메라에 안 나오면 분노하는데, "카메라 앞으로" 지시를 해도 분노가 풀리지 않는다.
- 출연자 클릭으로 클로즈업 대상을 바꾸는 조작이 별로다. 클릭은 아주 명시적이고 중심적인 행동인데 결과는 국소적이다. 카메라에서 출연자로 끌어 놓는 방식이 낫다.
- 무대 와이드 화면이 좌우로 뒤집혀 있다.

### 원인 (재현으로 확인)
- 무입력: 시작 출연자 4명의 반응이 모두 "다른 현상을 받으면"이라 스스로 시작하는 것은 60초마다의 코너 반응뿐이다. 정적에 반응하는 준은 벤치다. 시드 1 무입력 180초 로그 12줄 중 9줄이 정적이었다.
- 렉스: "카메라 앞으로"가 카메라 렌즈 위치로 한 번 미는 dash라 2m쯤 가다 멈췄고 시야 부채꼴 안에 들어가지 못했다. 화면 밖이면 8초마다 분노가 반복되고, 화난 포즈는 다른 행동이 바꿀 때까지 남았다.
- 좌우 반전: 피드 투영이 "yaw가 커지는 쪽이 왼쪽"으로 계산했는데 이 좌표계에서는 오른쪽이다. 단위 테스트가 같은 잘못을 고정하고 있었다.

- Ruling 13: 준 라인업 정적 줄 게이트(36/50)는 수치 조정을 멈추고 사용자 결정으로 올린다. 남은 손잡이는 게이트 해석(L6), 정적 줄 규칙, 버릇 간격 체감 목표뿐이고 모두 spec 수준이다.
- Ruling 14: 재촉 기준은 새 줄이 생긴 스텝이다(묶여 repeat만 오른 것은 치지 않는다). spec 5.2-4의 "묶인 줄은 1줄" 때문이며 Ruling 8을 대체한다. 무입력 지표(`livingMetrics`)의 공백 측정과 같은 기준이 된다.
- Ruling 15: 터짐 intenseLine도 `{target…}` 토큰을 대상으로 채운다(토큰이 있는데 대상이 없으면 targetLine 또는 line으로 돌아간다). plain 검사(토큰 금지, 빈 문자열 금지)를 `stageNames`·`stageLines`·상황 label의 noun·clause·버릇 noun으로 넓힌다.
- Ruling 16: 재촉 상수를 극 중 초(`LOG_NUDGE_SHOW_SECONDS` 40)에서 몸 초(`LOG_NUDGE_BODY_SECONDS` 4)로 바꾼다. spec 1.1의 로그 밀도 하한이 실제 초인데 극 중 초로 정해 쇼 배율이 다르면 어긋나던 L2 plan 결함을 고친 것이다. 토크쇼(배율 10)에서는 같은 240스텝이다.

## B1 무입력 검증(자동 PD) (2026-11-26, Plan B1 Task 8)

### 바뀐 검증 방식

- `npm run sim`의 기본은 **자동 PD 방송**이다(spec B1 2.4). 플레이어 입력 없이 자동 PD만 카메라를 돌린다. 시드 1~50 × 라인업 2개에 living spec 7.1 게이트 8개를 건다. 렉스 주목 욕구 게이트(9번째)는 기본 라인업에만 걸고, 준 라인업은 비율만 출력한다.
- 이어서 **고정 와이드**(카메라를 바꾸지 않는 지금까지의 무입력) 표를 참고로 출력한다. 게이트는 걸지 않고 종료 코드에도 영향이 없다. `--fixed`면 고정 와이드만 돌리고 게이트 8개를 건다(렉스는 비율만). `--log <seed> [june]`은 자동 PD 방송 로그이고, `--fixed`를 함께 쓰면 고정 와이드 로그다.
- 자동 PD는 6스텝(몸 0.1초)마다 부른다. 매 스텝 `view()`를 만들면 자동 PD 방송 한 판이 고정 와이드의 약 2배 걸렸다(50판 44초 대 20초). 자동 PD는 시간을 view.step 차이로 재고, 최소 유지가 몸 1.5초라 0.1초 늦게 보는 영향은 작다. 전체 `npm run sim`(400판)이 실제 약 114초(매 스텝, 조정 전 값)에서 84초(최종)로 줄었다.
- **렉스 1단계 판별은 엔진의 단계 진입 기록으로 센다(Ruling 2).** stage 줄로 세지 않는 이유는 두 가지다.
  - 같은 감정·단계 줄은 쿨다운(`STAGE_LINE_COOLDOWN_SHOW_SECONDS`, 실제 12초)이 걸리면 생략된다.

### 게이트가 깨진 원인(측정)

렉스 쌓임 12(spec 4)만 바꾼 자동 PD 첫 측정(시드 50)은 아래와 같았다.

- 기본 라인업: 큰 터짐 1~3회 27/50(평균 0.70), 렉스 1단계 2%.
- 준 라인업: 정적 줄 27/50, 작은 터짐 4~8회 28/50(평균 3.36).
- 고정 와이드 기본 라인업: 큰 터짐 평균 1.92, 모든 게이트 통과.

원인은 두 가지다.

1. **관객석 컷이 밋밋함을 끊는다.**
   - 관객석이 송출되면 관객이 실제 3초마다 소음(강도 1)을 낸다. 이 소음은 송출된 사고라 밋밋함(지루함의 연료)을 끊는다.
   - 컷 순서 와이드 → 클로즈업 → 와이드 → 관객석(설계상 각 5초, 한 바퀴 실제 20초)에서 관객 소음이 나면 자동 PD가 와이드로 옮기므로 관객석 컷은 약 2.9초다. 측정(시드 1~10)으로 관객석 컷은 평소 실제 분당 2.23회였다.
   - 확인 실험(측정 스크립트에서만 관객석을 뺀 순서): 큰 터짐 평균이 0.72에서 2.78로 돌아왔다.
   - 시드 1 로그에서도 "관객 쪽에서 소리가 난다"가 7번 송출된다(고정 와이드 0번).
2. **클로즈업과 관객석 컷에서는 화면 밖 출연자의 소리 버릇이 송출되지 않는다.** 그래서 방송 정적(실제 5초)이 끊기지 않고 정적 줄 비율이 올라간다. 평균은 고정 와이드 0.16, 자동 PD 0.19다.

### B2 플레이에서 사용자 확인

아래 변경은 무입력 검증에 맞추려 바꿨지만 수동 게임 화면에도 그대로 적용된다. 실제 시간 체감으로 적는다.

- **자동 PD 컷 몸 8초(5초에서, spec 2.3 값을 바꿈).** 게임 화면은 아직 수동이라 지금은 무입력 검증에만 영향이 있다. 나중에 "자동 연출"을 켜면 한 컷이 실제 8초로, 토크쇼 컷 범위(4~8초)의 가장 긴 쪽이다. 느긋하게 느껴지는지 본다.
- **상황 빠짐 극 중 분당 4 → 3.5.** 밋밋함이 끊길 때 지루함이 실제 초당 0.67에서 0.58만큼 빠진다. 사건 하나(다시 쌓이기까지 실제 5초)가 깎는 양이 3.3에서 2.9로 준다. 플레이어가 사고를 송출해도 출연자 지루함이 조금 덜 풀린다.
- **지루함 버릇 단축 0.4 → 0.55.** 지루함이 꽉 찬(100) 출연자는 버릇을 실제 4.5~9초 간격으로 한다(전에는 6~12초). 지루함 0일 때는 실제 10~20초 그대로다. 지루한 출연자가 부산스러워 보이는지 본다.
- **렉스 주목 욕구 쌓임 극 중 분당 7 → 12.** 렉스를 화면에서 빼면 실제 초당 2씩 쌓여, 이어서 실제 약 25초면 1단계다(전에는 약 43초).
- **렉스 주목 욕구 빠짐 극 중 분당 40 → 15.** 다시 화면에 잡아도 실제 초당 2.5씩만 빠진다(전에는 약 6.7). 1단계(50)에서 0까지 실제 약 20초다(전에는 약 7.5초). 잠깐 잡아 주는 것으로는 진정되지 않는다.
- 고정 와이드에서도 렉스 1단계 도달이 90%다(아래 관찰). 와이드만 두어도 렉스가 거의 매 방송 1단계에 닿는 것이 의도한 압력인지 본다.

### 관찰(조정 안 함)

- 고정 와이드에서도 렉스는 몸 시간의 약 16~20%를 화면 밖에 있다(시드 1~3, 몸 0.1초마다 표본). 렉스 도달이 90%로 높다. 원인(와이드 시야 가장자리, 카메라 감독 반응 등)은 확인하지 않았다. 게임 화면은 수동이라 플레이어가 와이드만 두면 렉스가 거의 매 방송 1단계에 닿는다. 이것이 의도한 압력인지는 B2 플레이에서 본다.
- 준 라인업 렉스 비율(26%)이 기본(50%)보다 낮다. 추정: 준 라인업은 큰 터짐이 많아(평균 1.78 대 1.32) 자동 PD가 사고 출연자를 따라가는 시간이 늘고, 그만큼 관객석 컷이 줄어든다(확인하지 않음).
