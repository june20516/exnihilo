- 회고: sim에 신호(평균 18~23턴, 교착)가 있었는데, 이를 "버티기" 체험으로 해석하지 못하고 숫자만 맞췄다.
- 다음 제안: 문장 두 개(적의 문장 = 매 턴 공개되는 위협, 고친 것은 그 턴 확정 / 나의 문장 = 적이 못 건드리는 빌드업, 낭독으로 터뜨림). 화면 전에 sim으로 전투 길이, 낭독 피해 분포, 방어·빌드업 선택 분기율을 측정한다.

## 흉조 축 실험 (2026-11-23)

계기: A 플레이에서 "공격할 틈이 없다"는 피드백, 그리고 프리셋마다 흉조 시점이 달랐던 문제(A·B는 실행 전, C는 플레이어 낭독 뒤).

변경: `RuleConfig.omen = { timing, every }`. `beforeExecution`은 플레이어 낭독을 포함한 이번 턴의 모든 실행보다 먼저 착탄한다. 프리셋 기본값은 `pre1`(실행 전·매 턴)이고, 이번 변경으로 C도 실행 전으로 통일했다. 지표 두 개를 추가했다. 낭비율은 실행 전에 지워진 단어의 비율이고, 최대 한 방은 한 턴에 적에게 준 피해의 최댓값(독 틱 제외)이다.

거미, 탐욕 봇, 60판 (승률 / 이겼을 때 HP 손실 / 평균 턴 / 최대 한 방):

| 흉조 | A | B | C |
|---|---|---|---|
| 실행 전·매 턴 | 92% / 32.6 / 18.5 / 15.3 | 85% / 34.6 / 22.7 / 16.5 | 100% / 12.8 / 13.8 / 14.2 |
| 실행 후·매 턴 | 100% / 0.0 / 6.6 / 10.1 | 100% / 0.0 / 10.3 / 11.6 | 100% / 0.0 / 8.9 / 9.8 |
| 실행 전·2턴마다 | 100% / 6.5 / 10.8 / 10.6 | 98% / 8.2 / 13.9 / 13.8 | 100% / 3.7 / 10.8 / 9.4 |
| 실행 후·2턴마다 | 100% / 0.0 / 7.2 / 9.0 | 100% / 0.0 / 7.6 / 8.2 | 100% / 0.0 / 10.7 / 8.4 |

해석:
- 흉조를 실행 뒤로 옮기면 모든 조합에서 HP 손실이 0이 된다. 적의 공격 수단이 "내가 고칠 수 있는 바로 그 문장" 하나뿐이어서다. 내 수정이 반드시 먼저 실행되면 적은 한 번도 때리지 못한다. 위협은 전부 "흉조가 내 수정을 실행 전에 지운다"에서 나왔다.
- 낭비율은 0~3%다. 봇은 흉조 슬롯을 피해서 둔다. 그러니 "틈이 없다"는 단어를 잃는 문제가 아니라, 공격 문장을 만들 수 없는 문제다.
- 주기 2(실행 전)는 중간값이지만 HP 손실이 4~8로 너무 쉽다.
- 최대 한 방은 흉조 축과 상관없이 8~17에 머문다. 한 방이 작은 원인은 문장 하나·수식어 2칸이라는 콘텐츠 구조다. 한계: 탐욕 봇은 한 수 앞만 보므로, 여러 턴에 걸친 빌드업은 과소평가된다.
- 결론: 문장 하나 구조에서는 "적의 위협"과 "내 캔버스"가 같은 대상이라, 흉조 시점이 곧 난이도 스위치가 된다(전: 교착 / 후: 무위협). 문장 두 개로 간다면, 적의 위협은 내 수정과 독립적으로 존재해야 한다.

- 주어와 목적어는 생략할 수 있어서 동사 한 장으로도 문장이 된다.

## 한 방 천장 분석 (2026-11-23)

질문: 지금 카드·강화·유물로는 10배가 수학적으로 불가능한 것 아닌가? 도구: `npm run ceiling` (`scripts/ceiling.ts`). 해석식으로 전수 탐색하고, 대표 문장은 실제 엔진으로 대조했다(일치).

1. **수식의 천장은 충분하다. 오히려 폭발한다.**
   - 배율은 칸 안에서 곱으로 쌓인다. 강화는 단어 종류 단위라 같은 카드 전부가 함께 오른다.
   - 강세는 부사 세기를 제곱한다. 격렬하게 2단계 2장이면 (2.5×2.5)² = ×39다.
   - 시작 덱 최고는 39다. 상점을 마음대로 고를 수 있다면:
     - 3번 구매(강세, 격렬하게 강화 ×2, 기본가 28)로 591 = 15배
     - 12번 구매로 187,500
   - 이론 천장(모든 것 최대, 손패 8)은 4,100,798이다.
2. **측정 버그: 한 방 기록이 적의 남은 HP에서 잘렸다.**
   - `applyDamage`의 `dealt = min(hp, …)` 합을 기록했기 때문이다. 보스 HP가 120이므로 "상위 25% ≥ 180" 게이트는 처음부터 달성할 수 없었다.
   - 수정: 낭독 때 같은 문장을 HP가 무한한 적에게 계산한 `sentencePower`를 기록한다.
3. **실제 상점 운에서도, 천장을 아는 구매자라면 닿는다.** 200런, 상점 6번:
   - 덱 천장은 중앙 450이고, 런의 83%가 180 이상이다.
   - 손패 8장 한 번으로는 중앙 80이다. 한 손패가 180을 넘을 확률은 17.6%다.
   - 병목은 손패 일관성이다. 동사 하나와 수식어 4~5장이 한 손에 모여야 한다.
4. **구매만 바꾼 실제 런 60회** (전투는 기존 두 수 앞 봇, 고친 측정):
   - 천장 구매자: 완주 68%, 한 방 상위 25% 120, 최대 222
   - 학습 봇: 47%, 66
   - 남은 간극은 전투 봇에 있다. 봇은 적을 끝내려고 두지 큰 문장을 노리지 않는다.
5. **설계 쪽 시사점**
   - 적 HP가 45~120이라 180을 만들 이유가 게임 안에 없다. 오버킬 보상(화폐 등)이 들어가야 큰 한 방을 노리는 동기가 생긴다.
   - 강세와 메아리는 산 런의 완주율이 90%다. 지배 유물이다. 울림은 17%로 함정이다.

## 상점 조합 재료 가중치 (2026-11-23)

배경: 플레이테스터의 시드 1001 런 두 번 모두, 상점에 새 부사·형용사·연결어가 한 번도 나오지 않았다. 이대로면 사람 테스트에서 빌드 레이어를 못 겪을 수 있다.

측정: 천장 분석 200런, 천장 구매자 실제 런 60회, 기존 정책 60런.

| 상점 규칙 | 천장 ≥180 런 | 천장 구매자 완주 / 한 방 상위 25% | 학습 봇 완주 / 한 방 | 유물 우선 | 상점당 조합 재료 |
|---|---|---|---|---|---|
| 원래 | 83% | 68% / 120 | 47% / 66 | 58% | 27% |
| A: 단어 칸 고정 + ×3 | 80% | 57% / 105 | 30% / 52 | 45% | 63% |
| **B: 가중치 ×3만 (채택)** | 86% | 73% / 120 | 48% / 66 | 63% | 47% |
| C: 단어+유물 칸 고정 | 94% | 88% / 128 | 40% / 76 | 55% | 63% |

- A가 나빠진 이유: 단어 칸을 고정하면 유물이 나오는 상점이 4곳 중 3곳에서 3곳 중 2곳으로 줄어든다. 유물이 가장 강한 보상이라 완주율이 떨어진다.
- C는 가장 세다. 하지만 유물이 매 상점에 나와 유물 쏠림이 심해지고, 잘하는 플레이어에게 너무 쉬울 수 있다.
- B는 모든 지표가 원래 규칙 이상이고 "종류가 다른 보상 3개" 규칙을 지킨다.
- 덧붙여 알게 된 것: 조합 재료가 더 자주 나와도 천장은 크게 오르지 않는다. 기계 기준 병목은 재료 수가 아니라 유물과 손패 일관성이다. 재료 가중치는 사람이 빌드 레이어를 겪게 하는 보정이다.

## 형용사 상태 도입 후 재측정 (2026-11-24)

규칙: 형용사는 꾸민 명사의 상태다. 지속 시간이 "적 차례까지"인 형용사(금이 간, 눈먼, 단단한, 독을 뿜는)는 낭독 뒤 그 개체에 남아, 이어지는 적 차례의 피해 계산에 들어간다. 천천히는 상점에서 뺐다.

- **기본 랠리 게이트**(`balanceGate.test.ts`): 7개 모두 통과
  - 거미: 승률 100%, HP 손실 29.6, 5.5턴
- **런 게이트**(평가 60런, 학습 가중치 그대로)
  - 학습 봇: 완주 48% → **57%**, 한 방 상위 25% 72 → 80
  - 처음으로 완주율 게이트(50~80%)를 통과했다.
  - 유물 우선: 65% → 73%. 독·연결어·구조·몰아 강화 유형: 17~28%(전에는 3~15%). 무작위: 22%, 안 삼: 0%
  - 남은 실패: 학습 봇 근처 유형 수 1(목표 3), 한 방 상위 25% 80(목표 180, 봇 기준이라 의미가 약함)
  - 교착 런: 유물 우선 5, 학습 1, 무작위 1
- **천장 분석**
  - 천장 180 이상인 런: 91%
  - 천장을 아는 구매자의 실제 런: 완주 77%, 한 방 상위 25% 120
  - 같은 시드의 학습 봇: 완주 57%
- **해석**: 눈먼·단단한이 공격 문장에 얹는 방어가 되면서, 유물이 없는 유형들의 완주율이 함께 올랐다. 수식어 칸에서 "세게 칠까, 적의 다음 공격을 깎을까"를 고르는 선택이 생긴 효과로 본다. 사람 테스트에서 이 선택이 실제로 고민되는지 확인한다.

형용사 상태 리뷰 반영(2026-11-24): 이번 절에서 불러낸 토큰(허수아비 등)과 허수아비 화자의 빈 주어에도 상태가 남도록 고쳤다. 이전 텍스트 플레이 저장 파일을 보정해 읽도록 했다.

측정 한계와 관찰 항목:
- 천장 분석(`ceiling.ts`)은 낭독 한 번의 즉시 피해만 잰다. 눈먼·단단한 같은 남는 방어 효과는 반영하지 않는다. 그래서 "천장을 아는 구매자"는 이 카드들을 사지 않는다. 완주율 상승은 전투 봇(적 차례 뒤 HP를 평가함)의 결과다.
- **사람 테스트 관찰 항목**: 효과가 없는 배치에도 상태가 표시된다. 예를 들어 나에게 독을 뿜는·눈먼, 적에게 단단한을 붙이면 "독을 뿜음 · 적 차례까지"가 뜨지만, 지금 적 문장은 나를 때리지 않거나 내가 적 차례에 공격하지 않으므로 아무 일도 없다. 문자 그대로는 맞지만, 플레이어가 무언가 일어나리라 기대하는지 본다.

사용자 결정(2026-11-24):
- 부풀어 오른다로 늘린 최대 HP는 그 전투에서만 유지된다. 다음 층으로 이어지지 않는다(현재 동작 유지).
