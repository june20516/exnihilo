# 문장 던전 사람 테스트 1회차 (2026-11-24)

- 진행: 본인 직접 플레이(설계자). 체크포인트 태그 `pilot-sentence-v2-pre-human`.
- 한계: 설계를 아는 사람이라 "규칙을 처음 읽는 사람"의 가독성은 검증하지 못한다.

## 확인된 것

- 숨겨진 규칙이나 설계가 따로 없는 구조로 느껴진다.
- 큰 숫자가 나온 이유를 설명할 수 있다(인과 가독성 통과).

## 관찰(원문 요지)과 분류

### A. 표시 (규칙 변경 없음)

| # | 관찰 | 사실 확인 |
|---|---|---|
| A1 | "당신이 당신을 막는다"가 어색하다 | 지원 동사의 빈 목적어를 '당신'으로 채운 결과가 문구에 그대로 나온다 |
| A2 | 나에게 적용되는 유물 등 증폭 요소가 늘 보였으면 한다 | 지금은 계산식에서만 보인다 |
| A3 | 강화한 단어 카드가 얼마나 강해졌는지 보였으면 한다 | 지금은 단계(+1, +2)만 보인다 |
| A4 | 서고·망각이 무슨 정보인지 모르겠고 쓰이지도 않는다 | 뽑을 더미·버림 더미 장수 표시 |

### B. 기본 규칙 (결정 구조: 파일럿 검증 초점)

| # | 관찰 | 사실 확인 |
|---|---|---|
| B1 | 일반 층은 보호·분노 같은 전략적 선택 없이 꾸준히 때리기만 해도 이긴다는 인상 | 핵심 관찰. 아래 B2~B5가 원인 후보 |
| B2 | 내 보호는 이어지지 않아 숨기·막기를 하고 싶지 않다. 적 보호는 몇 턴 가는 것 같다 | 규칙은 양쪽 같다(상대 차례 한 번을 넘기고 사라짐). 적은 자기 차례에 쌓아 내 공격을 막으므로 체감이 비대칭 |
| B3 | 3,3,3,3으로 넣을 때 12라면 0,0,0으로 참았다가 4번째에 12가 그대로 들어가는 건 재미없다. 참으면 12보다 커야 하거나, 적의 피해를 이용하거나, 판을 뒤집는 상태이상·기믹이 있어야 한다 | 지금은 참는 것에 보상이 없다(선형) |
| B4 | 손패가 너무 많아 보인다(UI 탓일 수도). 줄이면 동사가 안 들어오는 문제는 아주 약한 기본 동사(예: 때린다 3)를 늘 주어 해결 | 손패 8장 |
| B5 | 버리기도 많은 느낌. 턴당 한 번이 많은가, 동사가 많아서인가 | 턴당 1회, 한 번에 여러 장 |
| B6 | 근접·원거리는 왜 있는가 | 표시만 하고 규칙에 쓰이지 않는다(v1 흔적) |
