# 플레이테스터 에이전트 노트 (문장 던전 v2 런)

시도마다 "어떻게 됐는지, 왜 졌는지(또는 이겼는지), 다음엔 뭘 바꿀지"를 적는다. 다음 시도 전에 이 파일을 읽는다.

## 시도 1 (시드 1001)
- 결과: 7/7층 완주. 최대 한 방 84 (보스전, 42 ×2회 메아리)
- 산 것: 턴당 버리기 +1(S1), 동사 칸 +1 · 금이 간 강화 0→1(S2), 목적어 칸 +1(S3), 허수아비 화자 · 동사 칸 +1(S4), 생략의 미학(S5), 메아리 · 손패 상한 +1(S6)
- 상점 목록(시드 1001, 1회차 기준):
  - S1: 턴당 버리기+1(12) / 치유한다 강화(5) / 울림(18)
  - S2: 동사 칸+1(12) / 금이 간 강화(5) / 독의 문법(12)
  - S3: 숨는다(3) / 허수아비 화자(12) / 목적어 칸+1(12)
  - S4: 허수아비 화자(12) / 동사 칸+1(12) / 겁준다 강화(5)
  - S5: 생략의 미학(12) / 독을 먹인다(3) / 주어 칸+1(12)
  - S6: 메아리(18) / 겁준다(3) / 손패 상한+1(12)
  - 하나 사면 나머지 값 ×1.5
- 배운 규칙:
  - 계산식 = ((동사 기본 + 유물) × 부사들 + 힘 + 주어 가산) × 목적어 배수. 내림.
  - 분노한다는 부사 영향 없음. 힘은 층이 바뀌면 사라짐.
  - 손패가 가득 차면 새로 뽑은 카드가 버려진다 → 쓸모없는 카드는 버리기로 미리 비워야 강한 카드를 안 잃는다.
  - 허수아비 화자: 주어가 허수아비로 바뀜 → 막는다/숨는다 보호가 허수아비에게 가서 방어 불가. 굶주린 HP 손실도 허수아비가 받음.
  - 메아리: 연결어 없으면 첫 절 2회 실행 → 사실상 ×2. 시작 덱에 연결어가 없어 항상 발동.
- 이긴 이유: 적 HP가 낮아 2~4턴에 끝남. 부사 2장 + 금이 간이 한 손에 모이면 40~70.
- 다음엔: 큰 한 방 노리기. 금이 간 강화를 더 사고(S2에 또 뜨는지), 허수아비+생략의 미학+메아리 조합 유지, 손패 정리를 더 철저히. 동사 칸 4는 부사가 2장뿐이라 낭비였다.

## 시도 2 (시드 1001)
- 결과: 7/7층 완주. 최대 한 방 190 (보스전, 95 ×2회 메아리) — 목표 180 달성
- 산 것: 턴당 버리기 +1(S1), 금이 간 강화 0→1(S2), 허수아비 화자(S3), 생략의 미학 · 겁준다 강화(S4), 메아리 · 손패 상한 +1(S6). 동사/목적어 칸은 안 삼.
- 상점은 산 것에 따라 바뀐다: S3에서 허수아비를 사니 S4에 생략의 미학이 떴고, S5는 독의 문법/독을 먹인다/주어 칸.
- 최고 문장: 굶주린 허수아비가 금이 간 필경사를 격렬하게 격렬하게 벤다
  계산식: ((10 + 유물 4) × 2.25 + 힘 12 + 4) × 2 = 95 (×2회) = 190
- 핵심 발견:
  - 허수아비는 전투 안에서 유지되고 힘도 쌓인다. 메아리 덕에 분노한다 한 장이 힘 +4.
  - 보스가 거는 약화는 "탐험가"에게 걸려서 허수아비 공격에는 영향이 없었다.
  - 손패가 가득 차면 버려지는 건 새로 뽑은 카드다 → 콤보 5장(벤다, 격렬하게×2, 굶주린, 금이 간)을 손에 쥔 채로 몇 턴 버티며 힘을 쌓을 수 있다.
  - 보스 3턴 동안 분노 3번(힘 12), 맞은 피해 15+9 정도. 체력 32 남기고 한 방.
  - 카드 놓을 때 손패 번호가 당겨진다 → 큰 번호부터 놓으면 안 꼬인다. 동사 칸에 동사를 또 놓으면 조용히 교체된다(1회차에 실수로 치유한다로 바뀜).
- 다음엔(3회차 한다면): 허수아비 없이 "당신" 주어 + 방어 카드로 버티며 힘 쌓기가 되는지 비교. 동사 칸 +1은 부사 2장뿐이면 쓸모없음.
