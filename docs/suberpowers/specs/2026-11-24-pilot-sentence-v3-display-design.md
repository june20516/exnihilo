# 문장 던전 v3: 표시와 조작 정돈

기준 문서: `2026-11-24-pilot-sentence-v3-rules-design.md`(규칙 v3, 이 spec보다 먼저 구현)
근거: `docs/lab/playtest/human-1.md`, 사용자 요청(2026-11-24)

## 1. 왜

사람 테스트에서 나온 표시 문제를 고친다. 계산을 읽는 데 필요한 정보가 날것의 줄글로 흩어져 있고, 화면 전체가 명조체이며, 단어를 하나만 빼는 조작이 없다. 규칙은 바꾸지 않는다. 바뀐 규칙의 표시를 다듬는 것은 이 spec에 포함한다.

## 2. 원칙

- **한 화면**: 스크롤 없이 한 화면에 들어간다. 선택해서 여는 정보(툴팁)만 예외다.
- **시트가 아니라 툴팁**: 추가 정보는 게임답게 그 자리에 뜨는 툴팁으로 보인다. 화면을 덮는 시트, 서랍, 모달은 쓰지 않는다. 예외는 상점, 결과, 덱 편집처럼 이미 화면 단위인 것뿐이다.
  - 데스크탑: 마우스를 올리면 뜬다.
  - 터치: 탭하면 뜨고 다른 곳을 탭하면 닫힌다. 카드처럼 탭이 이미 선택에 쓰이는 요소는 길게 누르면 뜬다.
  - 툴팁 컴포넌트는 하나(`ui/Tooltip.tsx`)로 만들어 모든 곳이 같이 쓴다.
- **엔진이 구조를 내고, 화면이 그린다.** 화면은 문자열을 쪼개 해석하지 않는다. 미리보기, 계산식, 예고, 카드 설명, 상태는 엔진 쪽 함수가 구조화된 값(종류, 수치, 출처)을 돌려주고, 화면은 그것을 아이콘과 칩으로 그린다. 텍스트 플레이는 같은 구조를 글로 바꾼다.
- **이름은 바꾸지 않는다.** 서고, 망각, 낭독 등 화면 이름은 그대로다(`docs/lab/naming`).
- **아이콘**: 이미 불러온 Material Symbols Outlined를 쓴다. 상태와 행동 종류마다 아이콘 하나를 정해 한 표(`ui/icons.ts`)에 둔다.

## 3. 항목

### 3.1 문구: 막는다 (목록 10)

지원 동사의 목적어가 빈칸이라 주어와 같은 대상으로 채워지면, 문장 문구에서 목적어를 생략한다.
- 예: "당신이 당신을 막는다" → "당신이 막는다"
- 목적어를 직접 놓았으면 그대로 쓴다. 예: "당신이 허수아비를 막는다"

### 3.2 적용 중인 증폭 요소 패널 (목록 11)

화면에 늘 보이는 작은 패널을 둔다. 다음을 한 줄씩 보여 준다.
- 가진 유물: 이름과 효과 한 줄
- 구조: 칸 수, 손패 최대치, 버리기 횟수
- 강화한 단어: 단어와 단계
- 이번 전투의 내 상태: 힘, 약화 등

공간이 모자라면 접힌 요약(아이콘과 개수)으로 두고, 툴팁으로 펼친다.

### 3.3 강화 수치 (목록 12)

강화한 카드의 설명에 바뀐 수치를 "기본 → 지금"으로 보인다(예: 피해 10→13). 상점의 강화 상품에도 같은 표기를 쓴다.

### 3.4 서고·망각 열람 (목록 13)

- 서고·망각 숫자에 마우스를 올리거나 탭하면 툴팁으로 내용을 보인다.
- 서고는 순서를 감추고 단어별 장수로 묶어 보인다. 망각은 들어간 순서대로 보인다.
- 서고가 비어 있으면 "서고가 비면 뽑을 때마다 HP 2를 잃습니다" 안내를 함께 보인다. 수치는 규칙 값을 읽는다.

### 3.5 손패 겹침 (목록 14)

- 손패 카드를 가로로 겹쳐 놓는다. 카드가 많을수록 많이 겹친다.
- 마우스를 올린 카드는 위로 올라오고 맨 앞에 와서 전부 보인다. 선택한 카드도 맨 앞에 온다.
- 클릭, 드래그, 버리기 표시는 지금처럼 동작한다.
- 기본 동사 타일은 손패와 떨어진 고정 자리에 두고 겹치지 않는다.

### 3.6 놓은 단어 하나씩 빼기 (목록 15)

- 엔진에 행동 `unplace`(위치: 절·칸·head 또는 수식어 번호)를 추가한다.
- 뺀 카드는 손패로 돌아온다. 대가는 없고 버리기 횟수도 쓰지 않는다. 기본 동사는 고정 자리로 돌아온다.
- head를 빼도 같은 칸의 수식어는 남는다.
- 연결어 빼기는 지금의 `disconnect`를 쓴다.
- **조작**
  - 손패에서 고른 카드가 없을 때 놓은 단어를 누르면 뺀다.
  - 놓은 단어를 판 밖으로 끌어도 뺀다.
  - 고른 카드가 있을 때 칸을 누르면 지금처럼 바꿔 놓는다.
- 텍스트 플레이에 같은 명령을 추가한다.

### 3.7 날것의 텍스트 시각화 (목록 16)

- **a. 미리보기("낭독하면", "이어서 적의 차례")**
  - 개체마다 한 줄이다. HP는 "34 → 19"와 작은 막대로 보인다.
  - 변화는 칩으로 보인다: 피해, 보호(이월 턴 포함), 회복, 독, 상태.
  - 처치는 강조한다. 아무 일도 없으면 "변화 없음"을 보인다.
- **b. 계산식**
  - 항마다 출처 라벨이 붙은 칩으로 보인다. 예: 동사 10 · 격렬하게 ×1.5 · 수식의 사슬 ×1.5 · 유물 +2 → 22
  - 이를 위해 `ClauseCalc`의 항에 출처 이름(단어 문구, 유물 이름, 상태 이름)을 싣는다. 지금은 'relic' 같은 종류만 싣는다.
  - 결과 숫자는 숫자용 폰트로 크게 보인다. 반복과 처치, 무효 표시는 지금처럼 유지한다.
- **c. 적 예고**
  - 예고 문장은 문장용 폰트로 남긴다.
  - 그 아래에 행동 아이콘과 엔진이 계산한 수치를 붙인다. 예: 공격 14, 보호 8 (1턴 유지), 봉인 주어 칸
- **d. 카드 설명**
  - 줄글을 아이콘과 수치로 바꾼다.
  - 지속 시간(형용사)과 이월(보호)은 배지로 보인다.
  - 공격/지원 구분은 색으로 보인다.
- **e. 상태 표시**
  - 개체 아래 작은 글자를 아이콘 배지와 수치로 바꾼다. 보호는 덩어리별 이월을 배지 안에 작게 보인다.
  - 마우스를 올리면 이름, 뜻, 지속을 툴팁으로 보인다.
- **f. 배치**
  - 문장판 위아래의 빈 공간을 줄인다.
  - 계산식은 문장판 바로 아래, 미리보기는 오른쪽에 둔다.
  - 증폭 요소 패널(3.2)과 서고·망각을 왼쪽 아래에 모은다.
  - 1440×900과 1280×720에서 스크롤이 없어야 한다.
- **g. 적 초상화**: 이미지에 박힌 글자("문장 던전 - 전투" 등)가 이름과 겹친다. 글자가 보이지 않게 잘라 내거나, 자르기로 안 되면 그 이미지만 다시 만든다.

### 3.8 모바일: 가로 화면 강제

- 지원하는 방향은 가로뿐이다. 세로로 들면 게임 화면 대신 "가로로 돌려 주세요" 안내만 보인다(방향 미디어 쿼리). 브라우저가 방향 잠금을 허락하지 않으므로 안내 방식으로 강제한다.
- 기준 크기: 844×390(작은 휴대폰 가로)부터 데스크탑까지. 데스크탑에서 보이는 정보는 하나도 빼지 않는다.
  - 늘 보이는 것: 개체, 문장판, 계산식, 미리보기 요약, 손패, 서고·망각 숫자, 낭독·턴 종료·버리기
  - 툴팁으로 펼치는 것: 미리보기 상세, 증폭 패널 상세, 서고·망각 내용, 카드·상태 설명. 데스크탑에서도 같은 방식이라, 기기에 따라 정보가 달라지지 않는다.
- 레이아웃은 하나의 배치를 화면 크기에 따라 줄이는 방식으로 만든다. 데스크탑용과 모바일용을 따로 만들지 않는다. 글자와 카드 크기는 화면 높이에 비례하는 값(`clamp`, `dvh`)을 쓴다.
- 터치 입력
  - 배치: 카드를 탭하고 칸을 탭한다(지금 방식). 드래그는 dnd-kit 터치 센서로 한다.
  - 손패 펼치기는 탭으로 고른 카드가 맨 앞에 나오는 것으로 대신한다.
  - 터치 대상은 최소 40px이다.
- 주소창 등 브라우저 UI 때문에 높이가 줄어도 잘리지 않게 `100dvh`를 쓴다.

### 3.9 폰트 (목록 18)

`theme.css`에 쓰임별 토큰 네 개를 두고, 컴포넌트는 토큰만 참조한다.

| 토큰 | 폰트 | 쓰는 곳 |
|---|---|---|
| `--font-card` | Song Myung | 손패와 문장판의 단어, 카드 이름 |
| `--font-prose` | Hahmlet | 적 예고 문장, 낭독한 문장, 결과 문구, 제목 |
| `--font-ui` | Pretendard | 패널, 버튼, 라벨, 설명, 툴팁 등 나머지 전부 |
| `--font-number` | Do Hyeon | 계산식 결과, 피해·HP 숫자, 상점 가격 |

- 불러오기: Google Fonts CDN(Song Myung, Hahmlet, Do Hyeon), jsdelivr CDN(Pretendard).
- Noto Serif KR과 Space Grotesk는 지운다.
- 모두 OFL 라이선스다.

## 4. 범위 밖

규칙 변경, 새 카드, 캐릭터, Stitch 시안은 이 spec에 들어가지 않는다.

## 5. 검증

**엔진 테스트**
- `unplace`: head를 빼면 손패로 돌아오고 수식어는 남는다. 수식어를 빼면 손패로 돌아온다. 기본 동사는 손패에 들어가지 않는다. 빈칸을 빼려 하면 거절한다.
- 카드 보존 속성 테스트에 `unplace`를 섞어도 통과한다.
- 미리보기 구조값: 피해, 보호, 처치, 변화 없음이 테스트한 값과 같다.
- 계산식 항의 출처 이름이 단어, 유물, 상태 이름과 맞다.
- 예고 수치는 엔진의 적 차례 미리보기와 같은 값이다.
- 카드 설명 구조값과 강화 수치(기본 → 지금)가 맞다.
- 막는다 문구: 목적어를 생략하는 경우와 직접 놓은 목적어를 쓰는 경우

**e2e**
- 손패에 마우스를 올리면 그 카드가 전부 보인다(겹친 이웃에 가리지 않음).
- 놓은 단어를 누르면 손패로 돌아온다.
- 서고에 마우스를 올리면 내용 툴팁이 뜬다.
- 1440×900, 1280×720, 844×390(모바일 가로, 터치 에뮬레이션)에서 `expectInViewport`로 스크롤이 없다.
- 844×390에서 늘 보이는 정보 요소(testid 목록)가 모두 화면 안에 있다. 툴팁 요소는 탭하면 화면 안에 뜬다.
- 390×844(세로)에서는 "가로로 돌려 주세요" 안내가 보이고 게임 화면은 보이지 않는다.
- 터치 에뮬레이션에서 카드 탭 → 칸 탭으로 배치되고, 카드를 길게 누르면 설명 툴팁이 뜬다.
- 폰트 토큰이 실제로 적용된다. 카드 단어의 `font-family`가 Song Myung, 버튼이 Pretendard인지 계산된 스타일로 확인한다.

**사람 확인**: 고친 화면 캡처를 보고 사용자가 판단한다.
